# Deep Dive Program — Index, Queue, and Log

This folder holds recurring deep dives into the open problems catalogued in `../02_open_questions.md` and `../03_mmm_adoption_barriers.md`. A scheduled task runs every 4 hours; each run executes ONE dive under the full depth protocol per the rules below, writes it as `NN_<slug>.md` (code in `code/NN_<slug>.py`), and logs it here.

## Rules of the program

1. Work the queue in order, one item per run. Sequence numbers are permanent and zero-padded.
2. Every 4th run is an EXTEND run: instead of a new item, revisit the prior dive with the most promising "next steps" section and push it further (deeper derivation, better simulation, stronger counterexample, more complete design). Extensions get their own sequence number with the same slug + `_ext`.
3. Depth standard (full protocol, as of run 03): formalize mathematically with explicit assumptions; parallel literature subagent at dive start; minimum 3 construct→attack→refine rounds, iterating until two consecutive rounds produce no material revision; ≥8 numerical experiments incl. ≥2 robustness sweeps and ≥1 negative/power control; uncertainty estimates on every headline number and a devil's-advocate paragraph against every headline claim; a clean-room verification subagent re-derives at least one core result before writeup; separate established results from speculation with clear labels. Writeups include the attack-and-refine history.
4. Each dive ends with "Next steps for a future session" — the hook extensions build on.
5. If a dive discovers a new open problem, append it to the queue backlog with a one-line rationale.
